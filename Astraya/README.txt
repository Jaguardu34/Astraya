====================================
            REQUIREMENTS
====================================


[ PYTHON ]
------------------------------------
Version requise : Python >= 3.8

1. Aller sur le site officiel :
   python.org

2. Télécharger la dernière version de Python

3. Suivre les instructions d'installation

[ PYXEL ]
------------------------------------
Version requise : Pyxel >= 2.0.7

Installation :

- Ouvrir un terminal
- Exécuter la commande suivante :

    pip install pyxel==2.0.7

Si la commande "pip" n'est pas reconnue :

    python -m pip install pyxel==2.0.7

            INFORMATION

Après avoir installé Python et Pyxel lancer le fichier main.py et profitez du jeu
